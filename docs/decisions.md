# Architecture and Product Decisions

Record decisions in this format. Add the date, context, alternatives, decision, and consequences when a choice is made.

## Open decisions

- Initial launch geography and geographic unit
- Initial target audience and primary comparison workflow
- Frontend framework and package manager
- Backend entry point and migration tooling
- Indicator shortlist, weights, normalization, and missing-data rules
- Data source licensing, refresh cadence, and provenance requirements

## Decision record template

### YYYY-MM-DD — Decision title
- **Status:** Proposed / Accepted / Superseded
- **Context:** What prompted the decision?
- **Options considered:** What alternatives were evaluated?
- **Decision:** What was selected?
- **Consequences:** What follows from this choice?
